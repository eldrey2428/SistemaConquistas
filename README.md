# Sistema de Conquistas de Jogos

## Descrição
Este projeto é um sistema simples de gerenciamento de conquistas de jogos desenvolvido em PHP utilizando Programação Orientada a Objetos (POO).

O sistema permite cadastrar jogos, jogadores, conquistas e controlar o progresso de desbloqueio das conquistas.

---

## Funcionalidades

- Cadastro de jogos
- Cadastro de jogadores
- Cadastro de conquistas
- Controle de progresso das conquistas
- Desbloqueio automático ao atingir 100%
- Exibição de detalhes da conquista
- Registro de data e hora do desbloqueio
